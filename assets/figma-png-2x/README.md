## Подключение

PNG содержат готовые композиции из Figma, включая изображения, повороты, эффекты и внутренние подписи. Image4 и Image5 экспортированы по точным границам фреймов через временные копии с Clip content; копии после экспорта удалены. Остальные фреймы экспортированы напрямую. Масштаб каждого файла — 2× относительно размеров фрейма.

Пример из корня сайта:

```html
<img src="./assets/figma-png-2x/home/Image4@2x.png"
     width="668" height="584"
     alt="Приложение защиты от спам-звонков"
     style="display:block;max-width:100%;height:auto" />
```

При подключении используйте готовый PNG вместо прежних отдельных слоёв соответствующей иллюстрации. Не добавляйте повторный поворот или независимое растяжение ширины и высоты. Для адаптива сохраняйте пропорции изображения.

## Точные экспорты текущих фреймов кейса
