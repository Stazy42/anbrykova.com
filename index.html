Launching paid spam protection app

Launching of the second version of the MVP app Defender with the addition of the paid service Spam Call Blocker

Objectives

  1. Refine existing screens and flows
  2. Develop missing screens based on the approved concept
  3. Conduct testing of ambiguous scenarios

Results

  1. I completed the main tasks in the design part in 3 months, which helped speed up a quicker app release to the stores
  2. The number of active users grew by an average of 21% after launch of the second version of MVP
  3. SU accounted for 15% of the active user base

First and Second Versions of the MVP

The first version already available in the stores, only included the free feature of Caller ID, a spam complaint button, and onboarding. In the second version, we kept the Caller ID and spam complaint button, while also adding new sections and scenarios:

  • Profile with MTS ID authorization
  • Activation of the paid Spam Call Blocker feature
  • Subscription management
  • Call log and call details with transcription
  • Tips (FAQ)
  • Native spam call complaint feature

Changing Navigation Through the Main Screen

With the addition of the second service, it became necessary to place two activation points on the main screen, as without activating both services, the user would not have access to blocked calls, and the app would lose its functionality. The previous designer had implemented both services through widgets, which seemed like a convenient solution for a limited time period. But during the further exploration of the app, difficulties arose, particularly with error display and database updates within one of the widgets. I addressed the errors issue by moving the display to a separate banner, while the task of separating the database update from the widget was planned for the next iteration

Blocking spam calls

I developed a promo screen for the paid service and refined the activation flow, where the user needs to set up call forwarding to redirect spam calls to the Defender. This process was complex and required research. The forwarding screen was revised several times until the UX research revealed the best solution. The final version was a step-by-step instruction screen without images.

An additional screen was also created for a rare case. MTS subscribers cannot use the app for non-subscribers, but they can activate services through My MTS. When logging in as a subscriber, we direct them to an informational screen.

Spam Call Blocking Activation Screens

Call feed and call details

The app was developed for both Android and iOS simultaneously. The difference between two systems lay in the calls display. The Android version showed the entire call list of the subscriber, while for iOS users only blocked calls were shown. As a result, a new tab for all calls was added to Android, and blocked calls became available when the blocking feature was activated. On iOS, blocked calls are displayed in the Spam Call Blocker widget.

The list allowed users to see which blocked calls had a transcription. Initially, the transcription was only text-based, but later, we added an audio recording as well. By opening a call, users could view/listen to the transcription, see information about the number (company, region, spam category), and call the subscriber back.

Profile and Subscription Management

The user profile includes an entry point for MTS ID authorization, where only the subscriber's number is displayed without additional data. Here, users can also find information about the app, leave feedback, and manage their subscription for spam call blocking.

In the subscription management section, the current price, the date of the next payment, and a button to cancel the subscription are displayed. If the subscription is canceled, the app will remind the user to disable call forwarding to prevent calls from being disrupted.

Switching to the native complaint screen

Native Complaint

To expand the spam number database, we added a convenient complaint option in the iOS call app. When the user swipes a call, a complaint button appears, leading to a screen where they can file a complaint, block the number, and check the current status of the number database.
